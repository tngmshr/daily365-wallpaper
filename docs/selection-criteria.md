# 記念日の選定基準と採点表（案 v0.1 / 2026-10-03）

対象読者: 水道事業の社員。配分の目安: 仕事系 7割・ユニーク 2割・季節 1割（1年あたり約 255 / 73 / 37 日）。

## 1. 足切り（1つでも満たさなければ不採用）

| ID | 条件 | 判定のしかた |
|---|---|---|
| G1 事実確認 | 一次情報が1件以上ある | 法令（e-Gov）・官公庁/自治体・国連/国際機関・日本記念日協会の登録ページ・制定団体の公式ページ。Wikipedia・まとめ記事・PR TIMES だけは不可（補助としては可） |
| G2 職場で安全 | 職場の朝礼で話して問題ない | 政治的対立・宗教・性・ギャンブル・飲酒/喫煙の推奨・特定の個人/企業の宣伝を除外。災害・戦争の日は「防災・平和の教訓」として落ち着いた言い回しで載せる（10/3 本人確認済み） |
| G4 食べ物の販促ではない | 企業・業界団体・産地が販促のために定めた食べ物の記念日は不採用 | 10/3 本人決定。残すのは年中行事・学校給食・国連の日など。対象一覧は `docs/exclusions.csv` |
| G3 日付が確定 | その年の日付を一意に決められる | 毎年同じ日、または年ごとの日付データで持てる（成人の日・春分など） |

## 2. 採点（満点 10）

| 軸 | 点 | 基準 |
|---|---|---|
| A 仕事との接点 | 0〜4 | 4: 水道そのもの（水道記念日・水の日・世界水の日・水道法など） / 3: 安全・衛生・水質/品質・防災・設備/電気・計量・法令施行日 / 2: 働き方・健康・環境・科学技術 / 1: 雑談として職場で話せる / 0: 接点なし |
| B 出典の強さ | 0〜2 | 2: 法令・官公庁・国連 / 1: 日本記念日協会・制定団体の公式 / 0: G1 をぎりぎり満たすだけ |
| C 話題性 | 0〜2 | 由来・数字・語呂に「へえ」がある。一言で説明できる |
| D 季節感 | 0〜1 | その時期の行事・気候と結びつく |
| F 東京ゆかり | 0〜1 | 東京の出来事・施設・行事に由来する（10/3 本人の希望で加点） |
| E 企業PR 減点 | 0〜−3 | −3: 単一企業・商品の販促目的 / −1: 業界団体の販促寄り / 0: 公的・非営利 |

- 同じ日に候補が複数あれば合計点の高い順に 1〜4年目へ割り当てる。
- 区分（仕事 / ユニーク / 季節）は A≥2 なら「仕事」、D=1 で A≤1 なら「季節」、それ以外「ユニーク」。年間の配分を見て、同点のときに不足区分を優先する。
